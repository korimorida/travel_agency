Функциональные требования MVP
Основные модули системы
Главная страница:
Система должна отображать главную страницу с баннером, содержащим ключевое предложение турагентства (например, "Лучшие туры по России!").

Система должна предоставлять навигационное меню с разделами:

"Главная"

"Туры"

"Отели"

Система должна отображать контактные данные в шапке и футере сайта (например, номер телефона и ссылки на мессенджеры).

Модуль "Каталог туров"
Система должна отображать каталог туров в виде карточек, каждая из которых содержит:

Название.

Краткое описание.

Стоимость.

Кнопку "Узнать подробнее", которая открывает страницу с детальной информацией о туре.

Страница с детальной информацией о туре должна включать:

Полное описание программы.

Фотогалерею.

Условия тура.

Кнопку для подачи заявки на тур.

Модуль "Каталог отелей"
Страница с отелями:

Система должна отображать список отелей с возможностью фильтрации:

По названию.

По стране.

Каждому отелю должна быть посвящена отдельная карточка с кратким описанием и кнопкой "Узнать подробнее", ведущей на страницу с подробной информацией об отеле.

Страница с детальной информацией об отеле должна включать:

Описание отеля.

Фотографии.

Условия проживания.

Отзывы.

Кнопку "Забронировать" для подачи заявки.

Модуль "Подача заявки"
Форма подачи заявки должна быть доступна на страницах с туром и отелем.

Поля формы:

Имя (обязательное текстовое поле).

Телефон (с валидацией на корректность ввода номера).

После отправки формы:

Система проверяет корректность данных.

Если данные введены правильно, система сохраняет заявку и выводит сообщение об успешной отправке.

Если данные введены некорректно, система подсвечивает ошибочные поля и просит пользователя исправить их.

Технические требования
Два независимых проекта:
client-app — основное клиентское приложение.

ui-library — библиотека общих UI-компонентов.

ES6 модули (import/export).

TypeScript для статической типизации.

React для создания пользовательского интерфейса.

React Router для организации маршрутов.

mock API или JSON-файлы для хранения информации о турах, отелях и акциях.

Vite как сборщик проекта и dev-сервер.

Use Cases
Use Case 1: Просмотр главной страницы
Участники: Пользователь, Система отображения контента

Предусловия:

Пользователь зашел на главную страницу.

Основной сценарий:

Пользователь переходит на главную страницу.

Система отображает баннер с предложением тура.

Система отображает форму для поиска туров с фильтрами.

Система отображает блок с акциями.

Пользователь может прокрутить страницу и ознакомиться с предложениями.

Результат:

Пользователь ознакомился с основными предложениями и может выбрать тур.

Use Case 2: Подача заявки на тур
Участники: Пользователь, Система подачи заявки

Предусловия:

Пользователь заинтересовался туром и переходит на страницу с подробной информацией о туре.

Основной сценарий:

Пользователь нажимает кнопку "Оставить заявку".

Система открывает форму с полями "Имя" и "Телефон".

Пользователь заполняет поля и нажимает "Отправить заявку".

Система проверяет корректность данных.

Система сохраняет заявку и выводит сообщение об успешной отправке.

Результат:

Пользователь успешно подал заявку.

Use Case 3: Просмотр каталога туров
Участники: Пользователь, Система отображения туров

Предусловия:

Пользователь находится на сайте и переходит на страницу с турами.

Основной сценарий:

Пользователь нажимает на пункт меню "Программы".

Система отображает страницу с каталогом туров.

Система отображает карточки туров с названием, кратким описанием, стоимостью и кнопкой "Узнать подробнее".

Пользователь может отфильтровать туры по странам, типу и параметрам.

Результат:

Пользователь ознакомился с доступными турами.

Use Case 4: Просмотр каталога отелей
Участники: Пользователь, Система отображения отелей

Предусловия:

Пользователь находится на сайте и переходит на страницу с отелями.

Основной сценарий:

Пользователь нажимает на пункт меню "Отели".

Система отображает страницу с каталогом отелей.

Система отображает карточки отелей с названием, кратким описанием и кнопкой "Узнать подробнее".

Пользователь может отфильтровать отели по стране или названию.

Результат:

Пользователь ознакомился с доступными отелями.
