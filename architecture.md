Ключевые компоненты client-app:
Header — для отображения навигации между страницами (Главная, Туры, Отели и т.д.).

Footer — для отображения нижней информации о компании и ссылок.

TourCard — карточка с кратким описанием тура (например, название, изображение, цена).

ProductCard — карточка с детальной информацией об отеле (кнопка бронирования и описание).

FilterForm — форма с фильтрами для поиска туров и отелей по разным параметрам (страна, период вылета, длительность и т.д.).

Button — универсальная кнопка для бронирования, добавления в корзину и других действий.

Компоненты ui-library:
Button — универсальная кнопка для использования в различных частях приложения.

Input — поле ввода для различных данных, таких как текст, электронная почта, номер телефона.

Card — обертка для отображения информации, например, туров, продуктов и других объектов.

ProductCard — карточка с детальной информацией о туре, изображением, названием и кнопкой для бронирования.

TourCard — компактная карточка с кратким описанием тура (название, изображение).

PhotoGallery — компонент для отображения галереи изображений (например, для отображения фото туров).

Используемые библиотеки
#Runtime зависимости:

react (версия 18.0 и выше) — для создания компонентов UI.

react-dom (версия 18.0 и выше) — для рендеринга компонентов.

@my-app/ui-library — для использования общих UI-компонентов (например, кнопки, карточки, формы).

axios (версия 1.0 и выше) — для работы с HTTP-запросами.

material-ui/core (версия 5.0 и выше) — для использования готовых UI-компонентов (например, кнопки, поля ввода).

Dev зависимости:

vite (версия 3.0 и выше) — сборщик проекта и dev-сервер.

eslint (версия 9.0 и выше) — для линтинга и соблюдения стандартов кода.

jest (версия 30.0 и выше) — для тестирования компонентов.

react-testing-library — для тестирования React-компонентов.

Структура роутинга и отображаемых страниц
Клиентское приложение:
Главная страница (/):

Поисковая форма для поиска туров с фильтрами: страна, период вылета, длительность, тип питания, класс отеля и т.д.

Блок с акциями.

Страница с отелями (/hotels):

Список отелей с возможностью поиска по названию, стране или посмотреть весь список отелей.

Страница с турами (/tours):

Список туров с возможностью выбора по типу (горнолыжные, пляжные и т.д.) или по стране.

Сортировка туров по рейтингу, цене и популярности.

Страница с подробной информацией о туре (/tour/:id):

Детальная информация о выбранном туре, отзывы, подходящие рейсы.

Страница с подробной информацией об отеле (/hotel/:id):

Детальная информация о выбранном отеле, фотографии, условия проживания, отзывы, доступные рейсы.

Хранение данных
Для клиентского приложения данные могут храниться в локальном состоянии с помощью React hooks (useState, useContext). Для демо-версии можно использовать mock API или JSON-файлы для хранения информации о турах, отелях и акциях.
